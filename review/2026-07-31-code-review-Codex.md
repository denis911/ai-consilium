## Overview
The repository implements a Streamlit‑based research‑assistant that:
- Ingests optional RAG context.
- Queries a configurable set of LLM providers in parallel.
- Computes a consensus score based on embedding similarity.
- Synthesizes a final brief via an LLM‑as‑judge.
- Persists telemetry to DuckDB and optionally exports notes to an Obsidian vault.

The codebase is organized under the `council/` package, exposing clear boundaries between **providers**, **RAG**, **consensus**, **synthesizer**, **telemetry**, and **exporter** layers.

## Module‑by‑Module Review
### `app.py`
- **Strengths**: Clear Streamlit layout, caching of heavy objects, consistent UI styling.
- **Areas for improvement**:
  - Extract the four‑step consensus workflow into a dedicated service function (`run_consensus_workflow`) to keep UI code declarative.
  - Validate `vault_path` existence before exposing the export button.
  - Reduce the number of `st.sidebar.text` calls; consider a concise status summary.

### `council/consensus.py`
- Implements embedding similarity and outlier detection.
- **Suggestion**: Document the algorithm (e.g., cosine similarity matrix, DBSCAN threshold) and expose a `compute_score` helper that returns a plain `float` and a confidence interval.

### `council/providers.py`
- Handles parallel LLM queries.
- **Potential issue**: No exponential back‑off for rate‑limit errors. Add retry logic with jitter.
- Add explicit `asyncio.TimeoutError` handling to prevent a single provider from stalling the whole pipeline.

### `council/rag.py`
- Uses DuckDB in‑memory DB for temporary ingestion.
- **Recommendation**: Allow the caller to pass a persistent DB path for reproducible RAG results across sessions. Document the trade‑off between `:memory:` and file‑backed DB.

### `council/schemas.py`
- Contains Pydantic models (`ConsiliumQueryInput`).
- Ensure `strict` validation is enabled (`Config` with `extra = 'forbid'`) to catch malformed payloads early.

### `council/synthesizer.py`
- Wraps the LLM‑judge synthesis.
- Consider streaming partial responses to the UI for a more responsive experience.

### `council/telemetry.py`
- Logs runs to DuckDB and aggregates summary metrics.
- **Observation**: `log_query_run` returns a run‑id used for feedback. Ensure the run‑id column is indexed for fast lookup.
- Provide a cleanup routine to purge records older than a configurable retention period.

### `council/exporter.py`
- Exports Markdown notes to an Obsidian vault.
- Validate that `vault_path` is writable and does not overwrite existing files without confirmation.
